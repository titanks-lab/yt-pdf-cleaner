# 🚀 YT-PDFCleaner

> **PDF 跟踪水印一键清除工具 — 解压即用，无需安装**

---

## ✨ 功能

| 功能 | 说明 |
|:----|:------|
| 🎯 **单个处理** | 选一个 PDF，去水印保存 |
| 📁 **批量处理** | 扫描整个文件夹，自动检测水印并批量清除 |
| 🔄 **输出格式** | 可输出去水印的 **PDF**（保持原排版）或 **Markdown**（纯文本） |
| 🖥️ **图形界面** | 文件拖拽 + 进度条 + 结果汇总，操作直观 |
| 🌐 **命令行模式** | 也支持 `python main.py --cli --input file.pdf --output out.pdf` |

---

## 📥 下载（推荐）

### 🟢 绿色版（Windows）

从 [Releases 页面](https://github.com/titanks-lab/yt-pdf-cleaner/releases) 下载最新版：

```
YT-PDFCleaner-v1.0.0.zip
```

**使用方式：**
1. 下载 `.zip` 文件
2. 解压到任意文件夹
3. 双击运行 `YT-PDFCleaner.exe`

> ✅ **无需安装 Python、无需安装任何依赖、无需编译，解压即用！**

## 🔧 从源码运行（高级用户）

```bash
# 克隆
git clone https://github.com/titanks-lab/yt-pdf-cleaner.git
cd yt-pdf-cleaner

# 安装依赖
pip install -r requirements.txt

# 启动 GUI
python main.py

# 或使用 CLI 模式
python main.py --cli --input "带水印的文件.pdf" --output "去水印后的文件.pdf" --format pdf
```

## 🏗️ 自行打包

如果你修改了代码并想重新打包成绿色版：

```bash
# 安装打包工具
pip install pyinstaller

# 在项目根目录执行
python build/build.py
```

打包完成后，在 `dist/YT-PDFCleaner/` 目录下即可找到单文件绿色版 exe。

## 🔬 工作原理

水印在 PDF 文件中以**独立的内容流对象**存在（与正文不在同一流中）。本工具检测其特征：
- 灰色 `RGB(0.6, 0.6, 0.6)` 
- 斜向旋转矩阵 `0.93969`

找到后直接清空该内容流，保留原 PDF 全部排版、字体、页码、页面结构。

---

## ⚠️ 局限性

- **仅支持文本水印**（非图片水印）
- 水印颜色/旋转角度需在工具默认检测范围内
- 水印与正文在**同一内容流**中交织时无法直接清除（当前工具暂未实现流解析方案）
